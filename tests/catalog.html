3) Tile test (validación de variante aislada)

Renderiza UNA variante de tile a una coordenada iso arbitraria con una cámara controlada. Útil para verificar visualmente que una variante nueva (post-generación minimax o postprocess) tessella con sus vecinas sin overlap ni gap, y para comparar variantes lado a lado cambiando el offset iso.

cam iso: (0,0) tile gx,gy: (0,0) iso→screen Y: - step = tileSize/√2: -
Cómo usar:
  • Seleccioná una variante del dropdown (las 8 del stage activo).
  • Ajustá la cámara iso con X/Y para ver el tile desde distintos puntos de vista.
  • Cambiá gx/gy para reposicionar el tile aislado en el mundo iso.
  • "Llenar 5×5" pinta los 25 tiles alrededor de (gx,gy) usando el picker checkerboard del manifest — sirve para ver el patrón repetido de una variante junto a sus vecinas.
  • Si el tile tesella sin overlap ni gap con sus vecinos, el HUD muestra step = tileSize/√2 ≈ 90.5 (a tileSize=128). Si ves gaps o solapes, el problema está en la variante PNG o en el step math.
